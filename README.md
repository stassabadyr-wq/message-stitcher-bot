## Что делает бот

Собирает серию коротких сообщений в одно чистое. Пользователь пишет боту подряд, бот запоминает, потом по команде собирает всё в один аккуратный текст.

## Возможности полной версии

- 📥 **Сбор сообщений** — пиши боту подряд, он запоминает
- 🔗 **Умная склейка** — учитывает знаки препинания и заглавные буквы
- 👁 **Предпросмотр** — что уже в буфере
- 🗑 **Очистка** — с подтверждением
- 👥 **Работа в группах** — `/stitch` собирает сообщения пользователя
- 🛠 **Админ-панель** — статистика

## Умная логика склейки

- Заканчивается на «.» → новая строка
- Начинается с большой буквы → новая строка
- Начинается с маленькой → склеивает с предыдущим

**Пример:**

Вход:
```
Привет
как дела
Что нового?
У меня всё хорошо
```

Выход:
```
Привет как дела

Что нового?

У меня всё хорошо
```

Полный исходный код в ZIP:

- 🔒 `main.py` — полная точка входа с polling

## Установка демо

```bash
git clone https://github.com/stassabadyr-wq/message-stitcher-bot.git
cd message-stitcher-bot
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
cp .env.example .env
# заполни .env
python main.py
```

⚠️ **Демо `main.py` не запускает бота** — он только показывает структуру проекта.
